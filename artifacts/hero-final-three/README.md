# 히어로 최종 3종 인터랙션

- 4번째 POSITION SWAP 전용 파일, 실행·그리기·상태·정리 분기를 제거했습니다.
- 랜덤 선택은 ORIGINAL / ELASTIC BOUNCE / ORBIT MORPH 3개를 동일 확률로 선택합니다.
- 3번째는 2번째와 동일한 createSyncMotion 컨트롤러로 이동·회전·당김·반발을 처리합니다. 별도 공전, 방사형 보정, 스프링, 좌표 복귀 보정은 제거했습니다.
- 3번째의 기존 SVG 표시용 형태 보간과 전환 함수는 그대로 유지합니다. 각 방향 전환 0.71초, SYNC 유지 0.9초, DEFAULT 유지 0.5초입니다. 두 차례 전환과 마지막 DEFAULT 구간을 유지하기 위해 3번째의 기존 전체 재생 시간(약 6.9초)도 유지했습니다.
- SVG 원본, 1번째 모션, 2번째 물리 컨트롤러, 반응형 및 다른 페이지는 이번 작업에서 수정하지 않았습니다.

수정 코드: type-engine.js / sync-motions.js / orbit-morph.js. 제거 코드: position-swap.js.

검증:
- 300개 균등 난수 샘플: 각 효과 100회 선택.
- 1번째 모션 및 2번째 컨트롤러: 작업 직전 코드와 동일.
- 동일 초기 조건·난수·재생 길이의 414프레임 시뮬레이션에서 2번째와 3번째 좌표·회전 일치.
- SVG 전환 함수 작업 직전 코드와 동일, 완성 상태 유지 시간 및 종료 시 DEFAULT 확인.
- 대상 파일 ESLint 및 Vite production build 통과. 기존 500kB 번들 크기 경고 존재.
- 브라우저 결과는 existing-effects-checks.json 참고. Chrome 뷰포트 검증이며 실제 기기 검증은 아닙니다.
