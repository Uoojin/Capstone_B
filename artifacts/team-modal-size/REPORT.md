# TEAM 구도와 모달·X 크기 조정

이번 요청의 수정은 **1025~1599px 노트북 CSS 4개 파일**에 한정했습니다. JSX, 이벤트, 데이터, 이미지 경로, Supabase 코드는 수정하지 않았습니다. 기존 미커밋 변경은 그대로 보존했습니다.

## TEAM

기존 위 24px·아래 96px의 비대칭 여백 때문에 큰 이미지와 왼쪽 팀 정보가 화면 위쪽으로 치우쳤습니다.

- TEAM 상하 패딩을 각각 `6.6svh`로 균형 있게 조정했습니다.
- 중앙 이미지 높이는 `min(48.94vw, 86.8svh)`로 설정했습니다. 기존 가로 컬럼과 너비는 그대로이며, PC의 세로형 비율 및 화면 높이를 함께 반영합니다.
- 작은 이미지의 간격은 PC처럼 `5.5vw`로 조정했습니다.
- 팀명·라벨·작은 이미지의 크기, 오른쪽 명단 스타일은 변경하지 않았습니다.
- 소개 영역, 설명 4줄 규칙, 스크롤 스냅, 이전/다음·닫기 버튼의 기존 동작은 변경하지 않았습니다.

1512×850에서는 큰 이미지가 약 y=56px에서 시작하고 아래쪽 여백도 약 56px로 표시됩니다. 기준 이미지의 상하 약 6.6% 여백에 대응합니다. 높이가 더 긴 창에서는 기존 세로형 이미지 비율을 유지하며 중앙에 놓입니다.

## 모달 외곽과 X

제작 모달의 `--modal-width`만 다음처럼 줄였습니다.

```css
min(860px, 58vw, calc((100dvh - 240px) * 1190 / 626))
```

내부 요소의 순서, 컬럼 비율, 기존 크기 계산식·패딩·간격·텍스트 스타일 선언은 재작성하지 않았습니다. 기존 폭 기반 내부 치수가 모달 크기에 따라 함께 반영됩니다. 전체 transform scale/zoom은 추가하지 않았습니다.

상세 카드는 외곽 너비를 `min(290px, 20vw, (100svh - 220px) × .66)`로 줄였습니다. 내부 이미지·텍스트·패딩은 유지했습니다.

포토부스는 외곽 너비를 `min(100%, 680px, (100dvh - 340px) × 1.25 + 36px)`로 줄였습니다. 미리보기 비율 1.25:1 및 하단 버튼 구조는 그대로입니다.

- SYNCOPATE 두 X: 48→32px, SVG 24→16px.
- 포토부스 X: 36→32px, × 글자 26→20px.
- 상세 카드의 X 가로 중심과 배경 여백은 작은 버튼 크기에 맞게 보정했습니다.
- 모달/X 사이의 기존 24px(SYNCOPATE), 22px(포토부스) 간격은 유지했습니다.

| 뷰포트 | 제작 모달 너비 전→후 | 상세 카드 전→후 | 포토부스 전→후 |
|---|---:|---:|---:|
| 1512×982 | 약 998→860px | 340→290px | 812→680px |
| 1440×900 | 약 950→835px | 340→288px | 811→680px |
| 1366×768 | 약 902→792px | 약 328→273px | 646→571px |

## 실제 검증

Chrome의 CSS 뷰포트를 지정하고 DPR 2 환경에서 확인했습니다. 사용자가 열어 둔 실제 Chrome 창을 직접 측정한 결과는 아닙니다.

### 노트북

- 1512×982
- 1512×850
- 1440×900
- 1366×768
- 1280×720
- 1025×700

각 크기에서 17개 프로젝트를 실제 휠 입력으로 TEAM에 진입시켜 총 102개 상태를 확인했습니다.

- TEAM 상단 정렬 오차 1px 이내.
- 이전 소개 이미지가 화면에 남는 사례 0건.
- 큰 이미지 또는 작은 이미지가 뷰포트 밖으로 잘리는 사례 0건.
- 소개 섹션과 자식 요소의 주요 계산 스타일을 수정 전 CSS와 비교: 6개 크기 모두 차이 0건.
- 세 모달의 X 클릭 영역 모두 32×32px.
- 제작 모달·메시지·공유·X, 상세 카드·X, 포토부스·카메라·X 모두 화면 안에 위치.
- 포토부스 `scrollWidth === clientWidth`: 가로 넘침 0px.
- 브라우저 가상 카메라의 미리보기 스트림 및 X 닫기 확인.
- 드로잉 전후 이미지 변화, 되돌리기 시 원본 PNG 일치, 다시 실행 시 그리기 후 PNG 일치: 모든 크기에서 통과.
- 오브젝트 상세 모달은 테스트용 API 응답의 오브젝트를 클릭해 확인했으며 실제 서버 데이터를 변경하지 않았습니다.

실제 카메라 하드웨어, 서버 공유·저장 게시를 새로 실행한 검사는 아닙니다. 해당 로직과 이벤트는 이번에 수정하지 않았습니다.
