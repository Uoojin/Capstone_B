# 노트북 반응형 재수정 결과

기준은 이번 요청을 받았을 때의 작업 폴더입니다. 이전부터 존재한 미커밋 변경은 보존했습니다. 이번 변경만 보려면 `task-changes.patch`를 확인하면 됩니다.

## 변경 범위

노트북의 기존 경계인 **1025~1599px** 안에서만 CSS를 수정했습니다. 1600px 이상, 1024px 이하의 기존 규칙은 그대로입니다. HEADER는 HOME의 기존 크기를 공통 기준으로 사용하며 HOME의 본문·레이아웃·인터랙션 파일은 수정하지 않았습니다.

수정 파일은 다음 7개입니다.

| 파일 | 문제였던 규칙 | 수정 |
|---|---|---|
| `src/components/Header/Header.css` | `.site-header--subpage`만 높이·폰트·상단 여백을 줄이는 노트북 규칙. 활성 표시가 붙으면 기본 버튼의 실제 너비가 미세하게 달라짐 | 서브페이지 전용 크기 규칙 제거. HOME의 기존 공통 헤더를 사용. 노트북 기본 메뉴 버튼 너비를 104px로 명시해 활성 표시도 같은 박스 안에 배치 |
| `src/components/Header/Header.jsx` | 서브페이지에만 별도 클래스 부여 | 사용하지 않게 된 구분 클래스 제거. 상태·메뉴·활성 표시 로직은 그대로 |
| `src/pages/Project/Project.css` | 스크롤러 높이가 `calc(100% - 72px)`라 하단 버튼 위에 전체 폭의 스크롤 경계가 생김 | 스크롤러를 100% 높이로 복원. TEAM 끝에 하단 탐색 여유 공간을 확보하고 scroll-padding을 지정. 내비게이션 버튼에만 흰 배경을 적용하여 텍스트 가독성 확보. 중앙 전체를 가르는 불투명 하단 띠는 없음 |
| `src/pages/Student/Student.css` | 뒷면 패딩 16px/12px, 인터뷰 12px, 링크 11px | 뒷면 패딩 25px, 인터뷰 16px·줄간격 1.55, 링크 14px. 상·하단 사이 여유 20px. 링크 라벨과 값은 그리드로 정렬 |
| `src/pages/Content/DrawingEditor.css` | 66vw 너비와 별도 400~480px 높이·작은 도구 크기가 각각 적용됨 | PC 외곽 1190:626 및 내부 1.59:1 비율을 기준으로 하나의 모달 너비에서 크기를 결정. 화면 높이와 닫기 공간을 함께 반영. 캔버스 위치 보정도 같은 기준 사용 |
| `src/pages/Content/Syncopate.css` | 카드 모달 330px 상한·작은 폰트. 기존 높이 650px 이하 규칙의 상단 정렬 및 이미지 max-height가 노트북에도 적용됨 | PC 카드 390px 상한과 15px 본문/정보 글씨 복원. 노트북 안에서만 중앙 정렬·정사각 이미지 복원. 기존 24px 닫기 간격 유지 |
| `src/pages/Curriculum/Curriculum.css` | 제목 `min(7.32vw, 12svh)`로 화면 높이가 낮을수록 타이포그래피가 작아짐 | 높이 상한 제거. 80~125px의 폭 기반 큰 제목 사용. 낮은 높이에서는 제목 대신 심볼·설명 사이 여백만 줄임 |

PROJECT의 정상 소개 레이아웃, TEAM 중앙 이미지의 기존 노트북 크기, 작은 이미지 크기는 추가로 줄이지 않았습니다. 스크롤 로직, 애니메이션, 이벤트, 데이터, 에셋, 링크, 라우팅은 변경하지 않았습니다. HEADER의 JSX 변경은 클래스 제거뿐입니다. 페이지 전체 scale/zoom은 추가하지 않았습니다.

## 상세 스크롤 수정

이전에는 뷰포트 높이가 768px이어도 스크롤 영역이 696px에서 끝나므로, 화면 중간처럼 보이는 지점에서 콘텐츠가 잘렸습니다. 이제 스크롤 영역의 하단은 실제 화면 하단입니다.

TEAM은 마지막 콘텐츠 뒤에 내비게이션을 위한 여유 공간을 두며, 버튼은 기존처럼 왼쪽/오른쪽 하단에 남습니다. 버튼 바탕만 흰색으로 처리해 스크롤하는 콘텐츠와 탐색 텍스트가 직접 겹쳐 읽히는 것을 방지했습니다. 화면 전체를 가로지르는 별도 하단 마스크는 만들지 않았습니다. 콘텐츠는 기존 내부 스크롤을 통해 모두 접근할 수 있습니다.

## 카드 뒷면

테스트용 문장 “서로 다른 생각을 연결해 새로운 경험을 만듭니다.”를 브라우저 DOM에만 넣어 확인했습니다. 데이터 파일은 수정하지 않았습니다.

1512/1440/1366/1280px 모두 25px 패딩, 16px 인터뷰, 14px 링크로 계산되었으며, 테스트 문장은 두 줄(약 49.6px)로 표시되고 하단 링크와 겹치지 않았습니다. 긴 실제 문장은 내용 삭제나 줄 수 제한 없이 자연스럽게 더 줄바꿈되며, 필요하면 기존 카드 내부 스크롤로 접근합니다.

카드 앞면·비율·플립·단일 카드 선택 로직은 그대로입니다.

## 모달 결과

생성 모달은 너비를 `min(1190px, 78vw, (100dvh - 168px) × 1190 / 626)`로 정하고, PC 비율에서 패딩·간격·캔버스·패널 크기를 결정합니다. 메시지와 공유 버튼은 오른쪽 하단에 유지됩니다. 모달과 닫기 버튼을 포함한 그룹의 중심이 화면 중심에 놓입니다.

- 측정된 생성 모달 외곽 비율: 약 1.901, PC의 1190:626과 일치.
- 왼쪽/오른쪽 컬럼: 1.59:1.
- 생성 모달 그룹 중심과 화면 중심 차이: 0.01px 이하.
- 공유·닫기 버튼 모두 테스트 화면 안에 위치.
- 캔버스가 프레임 안에 위치하며 그리기 전후 픽셀이 달라짐 확인.
- 되돌리기 결과가 그리기 전 PNG와 일치, 다시 실행 결과가 그리기 후 PNG와 일치.

공유 오브젝트 상세 모달은 테스트 브라우저의 API 응답만 가로채 테스트용 오브젝트를 공급했습니다. 실제 서버 데이터는 변경하지 않았습니다. 기존 클릭 동작으로 모달을 열었습니다.

| CSS 뷰포트 | 카드 너비 | 이미지 비율 | 카드/닫기 간격 | 그룹 중앙 |
|---|---:|---:|---:|---|
| 1512×982 | 390px | 1:1 | 24px | 화면 중앙 |
| 1440×900 | 390px | 1:1 | 24px | 화면 중앙 |
| 1366×768 | 382.47px | 1:1 | 24px | 화면 중앙 |

본문 길이에 따라 카드 높이는 자연스럽게 늘어납니다. 서버 공유/저장 업로드는 실행하지 않았습니다.

## 브라우저 검증

Chrome에서 CSS 뷰포트를 지정하고 `innerWidth`, `innerHeight`, DPR 2 환경으로 검증했습니다. 사용자가 열어 둔 실제 Chrome 창을 읽은 측정은 아닙니다.

### 노트북

- 1512×982
- 1440×900
- 1366×768
- 1280×640 추가 확인

HOME, PROJECT, STUDENT, SYNCOPATE, GUESTBOOK, CURRICULUM, BEHIND의 7개 페이지에서 기본·확장 헤더를 비교했습니다. 최종 28개 화면/페이지 조합(각 2개 메뉴 상태)에서 HOME 대비 위치·크기·폰트·패딩·마진 차이 0건입니다. 비교는 웹폰트 로딩과 메뉴 애니메이션 완료 후 수행했습니다.

네 노트북 크기에서 각각 17개 상세페이지를 순회했습니다. 스크롤 영역 하단은 각각 982/900/768/640px로 실제 뷰포트와 일치합니다. TEAM 정착 화면과 섹션 사이 스크롤 위치도 캡처했습니다. 이미지 크기를 더 줄여서 하단 경계를 감추는 방식은 사용하지 않았습니다.

### 보존 검사

- `npm run lint`: 통과.

## 제한과 산출물

데이터에 사진·프로젝트 이미지·인터뷰가 비어 있는 항목은 기존 플레이스홀더나 빈 칸으로 표시됩니다. 실제 에셋과 콘텐츠는 변경하지 않았습니다. 두 줄 검증과 오브젝트 상세 모달 검증은 테스트용 콘텐츠를 사용했으며 브라우저 안에서만 공급했습니다.

- `task-changes.patch`: 이번 요청의 변경만 포함.
- `before/`: 이번 요청 시작 시점의 비교 원본.
- `layout.json`: 첫 화면 레이아웃 측정.
- `checks.json`: 상세 순회, 드로잉, 31개 보존 비교. 이 파일의 초기 헤더 및 오브젝트 클릭 결과에는 최종 보정 전 결과가 포함되므로 해당 두 검사는 다음 파일을 기준으로 확인합니다.
- `final-checks.json`: 최종 전 페이지 헤더 비교, 애니메이션 종료 후 오브젝트 상세 카드 측정.
- `team-*.png`, `team-transition-*.png`: TEAM 및 스크롤 중간 캡처.
- `student-*.png`: 테스트용 두 줄 인터뷰 캡처.
- `drawing-final-*.png`, `object-detail-*.png`: 생성·상세 모달 캡처.
- `curriculum-*.png`: 타이포그래피 캡처.
