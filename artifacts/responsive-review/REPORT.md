# 반응형 레이아웃 정리 결과

이번 작업 시작 시점의 작업 폴더를 기준으로 변경했습니다. 이미 수정되어 있던 데이터·다른 페이지·기능 코드는 보존했습니다. 이번 작업만의 차이는 `task-changes.patch`에서 확인할 수 있습니다.

## 수정 파일

| 파일 | 변경 내용 |
|---|---|
| `src/pages/Project/Project.css` | 소개 섹션의 문서 흐름 기반 3열/태블릿 2열, 캐러셀 카드 크기, 리스트 컬럼·필터·목록 간격 |
| `src/pages/Project/Project.jsx` | 768~1599px에서만 실제 CSS 카드 너비를 기존 궤도 배치 계산에 전달하는 5줄 추가 |
| `src/pages/Student/Student.css` | 노트북 카드 4열·독립 사이드바, 태블릿 카드 3열·상단 필터, 카드 뒷면 정보 접근성 |
| `src/pages/Content/DrawingEditor.css` | SYNCOPATE 모달에 한정한 크기·패널 비율·간격·높이 보정 |
| `src/components/Header/Header.css` | 노트북·태블릿 버튼과 확장 메뉴의 크기·여백 조정 |

TEAM 선택자·데이터·이미지·라우팅·랜덤/정렬·이동/애니메이션 로직·스크롤 유도 안내는 변경하지 않았습니다. 기존 상세 스크롤러의 901~1439px 높이 규칙도 보존했습니다.

## 적용 구간

| 구간 | CSS 뷰포트 너비 | 처리 |
|---|---|---|
| PC | 1600px 이상 | 기존 cascade 유지 |
| 노트북 | 1025~1599px | 중간 화면 공통 레이아웃 적용 |
| 태블릿 | 768~1024px | 중간 화면 공통 규칙 + 태블릿 재배치 |
| 모바일 | 767px 이하 | 기존 cascade 유지 |

새 규칙은 모두 최소 768px·최대 1599px 경계를 가집니다. 공통 전역 변수 변경, 페이지 전체 scale, 신규 !important 추가는 없습니다. 기존 PC·모바일에 필요한 과거 규칙은 대규모 삭제하지 않고 유지했습니다.

## 수정 전 미디어쿼리 분석

- Header: 900px, 767px 이하. 900px 이하의 가로 스크롤 메뉴가 태블릿에 적용되고 있었으며, 새 태블릿 규칙은 펼친 메뉴가 화면 안에 들어오도록 크기를 조정합니다.
- Student: 1100px 이하, 1024~1799px, 1024~1280px, 900px 이하, 600px 이하, 767px 이하. 1100px 이하의 3열과 1024px 이상의 4열 규칙이 중첩되고, 사이드바 너비 보정이 여러 번 덮어쓰였습니다. 중간 화면의 최종 너비·열 수를 한곳에서 결정합니다.
- Project 목록/캐러셀: 1100px 이하, 901~1799px, 900px 이하, 600px 이하, 767px 이하. 카드 너비가 CSS에서 축소되어도 JS는 별도 너비로 궤도 간격을 계산하고 있었습니다. 중간 구간에서 렌더링 너비를 읽어 기존 계산식에 연결했습니다. 리스트의 추가 max-width 축소도 중간 구간에서 해제했습니다.
- 상세 소개: 901px 이상에서 절대 좌표, 901~1439px에서 그리드, 900px 이하에서 단일 열. 1440px을 경계로 문서 흐름이 달라졌습니다. 소개에 한정한 기존 901~1439px 보정을 새 중간 구간 규칙으로 통합했고, 스크롤러·TEAM 관련 규칙은 유지했습니다. 480px 이하 TEAM 규칙도 그대로입니다.
- DrawingEditor: 1024px 이하 2개 블록, 767px 이하 6개 블록, 768~950px, 1025px 이상 3개 블록, 768~1024px, 1050px 이하. 모달 전용 선택자가 공통 편집기 규칙을 다시 덮는 구조입니다. 기존 공통 편집기·PC·모바일은 보존하고, 마지막의 모달 전용 중간 구간에서 최종 크기를 결정합니다.
- Syncopate.css: 높이 650px 이하 규칙은 메시지 조회 모달용입니다. 요청한 드로잉 모달과 구분하여 변경하지 않았습니다.
- hover/pointer·prefers-reduced-motion 쿼리는 기능 보존을 위해 유지했습니다.

## 주요 결과

- 상세 소개: 노트북 3열. 중앙 부제목·설명·이미지의 왼쪽 정렬선 일치. 설명 길이에 따라 행 높이가 늘어나며 카테고리는 독립 컬럼에서 상단 정렬·줄바꿈. 태블릿은 제목/카테고리와 설명/이미지의 2열 배치.
- 학생: 노트북 4열, 태블릿 3열. 앞·뒷면의 4:5 비율 유지. 긴 뒷면 정보는 카드 안에서 스크롤 가능.
- 프로젝트 목록: 노트북 3열, 태블릿 2열. 오른쪽 번호·팀명 목록 유지. 필터 후에도 목록 순서 불변.
- 캐러셀: 기존 회전·이동 계산식과 상호작용 유지. 카드 크기는 가로 너비와 화면 높이를 함께 반영하고, 그 너비를 기존 궤도 계산에 전달.
- 모달: 노트북 최대 너비 1050px, 캔버스/패널 비율 1.59:1. 낮은 높이에서는 기존 오버레이 스크롤을 통해 공유·닫기 버튼 접근 가능.
- 헤더: 노트북 36px 높이 버튼, 태블릿은 폰트·버튼 너비 추가 조정. 확장 메뉴가 화면 안에 표시됨.

## 검증의 한계와 산출물

현재 데이터에 학생 이름·사진·프로젝트 대표 이미지가 비어 있는 항목이 많아 캡처에는 기존 플레이스홀더가 표시됩니다. 첨부 피그마와 이미지가 채워진 상태의 완전한 시각적 일치까지 확인할 수는 없습니다. 기존 라운드·이미지 비율과 미입력 데이터의 동작은 보존했습니다.

- `results.json`: 39개 조합의 측정값. 모달 높이를 한 차례 보완하기 전의 초기 노트북 측정도 포함합니다.
- `interaction-results.json`: 최종 모달 9개 크기와 전체 프로젝트 순회·목록 순서 검증 결과.
- `preservation-results.json`: PC·모바일 픽셀 비교 및 학생 검색·필터 결과.
- `syncopate-*-final.png`: 최종 모달 캡처.
- `carousel-*.png`, `list-*.png`, `project-*.png`, `student-*.png`: 레이아웃 검토용 캡처. 캐러셀은 기존 자동 회전의 한 프레임입니다.
- `task-changes.patch`: 이번 작업 시작 시점 대비 변경만 포함한 패치.
